# model: Implementation Plan

**Spec:** docs/specs/2026-11-27-model-design.md
**Goal:** Put a `Model` trait in the seat `Client` holds today in `Agent` and `Summarizer`, so any crate can supply the model.
**Architecture:** A new `src/provider.rs` holds the `Model` trait, `ModelFuture`, the `Client` impl and forwarding impls for `Arc` and `Box`. `EventStream` gains a public `from_response` so the trait's default `stream` can replay a finished response. `Agent` and `Summarizer` hold `Arc<dyn Model>`.

## Global constraints

- No new dependency.
- Rust 1.88, edition 2024, the MSRV CI checks.
- Every trait keeps boxed futures so it stays usable as `dyn`.
- The agent loop, pinned turns, the repair pass, tool dispatch and the request built for each turn behave exactly as today.
- `cargo fmt --check`, `cargo clippy --all-targets --all-features -- -D warnings`, `cargo test --all-features` and `RUSTDOCFLAGS="-D warnings" cargo doc --no-deps --all-features` all pass.
- Public API changes are recorded in `CHANGELOG.md` under Unreleased.
- Any call to a real LLM server uses as few tokens as possible: send "hi" and have the model answer only "hi". This run makes none.
- Commit messages carry no Co-Authored-By line and no generated-by footer.
- `CHECK` below means: `cargo fmt --check && cargo clippy --all-targets --all-features -- -D warnings && cargo test --all-features && RUSTDOCFLAGS="-D warnings" cargo doc --no-deps --all-features` (add `--offline` to the cargo commands if the network is unreachable).

```rust
    /// A stream that replays a finished response: its content in order,
    /// text and refusal each as one delta, then [`StreamEvent::Done`].
    ///
    /// What [`crate::Model::stream`] returns by default, so a model that
    /// cannot stream still serves a streaming caller. [`EventStream::into_response`]
    /// returns `response` unchanged.
    pub fn from_response(response: GenerateResponse) -> Self {
        let mut queued = std::collections::VecDeque::with_capacity(response.content.len() + 1);
        for part in &response.content {
            queued.push_back(match part {
                OutputContent::Text(text) => StreamEvent::TextDelta(text.clone()),
                OutputContent::Refusal(text) => StreamEvent::RefusalDelta(text.clone()),
                OutputContent::ToolCall {
                    id,
                    name,
                    arguments,
                } => StreamEvent::ToolCall {
                    id: id.clone(),
                    name: name.clone(),
                    arguments: arguments.clone(),
                },
                OutputContent::Reasoning { data } => StreamEvent::Reasoning { data: data.clone() },
            });
        }
        queued.push_back(StreamEvent::Done {
            id: response.id.clone(),
            model: response.model.clone(),
            status: response.status.clone(),
            usage: response.usage,
        });
        let endpoint: Arc<str> = Arc::from(response.model.as_str());
        Self {
            endpoint: endpoint.clone(),
            body: Body::Done,
            buffer: SseBuffer::default(),
            decoder: None,
            assembler: Assembler::new(endpoint, false),
            queued,
            closed: true,
            read: 0,
            replayed: Some(response),
        }
    }
```

  Adjust field order and names to the struct as it stands after Step 1.

- [ ] Step 4: Create `src/provider.rs`:

```rust
//! The model an agent talks to, as a contract any crate can implement.

use crate::{Client, Error, EventStream, GenerateRequest, GenerateResponse};
use std::future::Future;
use std::pin::Pin;
use std::sync::Arc;

/// The future returned by every [`Model`] method.
pub type ModelFuture<'a, T> = Pin<Box<dyn Future<Output = Result<T, Error>> + Send + 'a>>;

/// Something that answers a [`GenerateRequest`].
///
/// [`Client`] is one, for every provider Freyja has a dialect for. A crate
/// can implement it for a provider Freyja does not speak, for a cache or a
/// router wrapped around another model, or for a fake that answers from a
/// script so an agent is tested without a network. [`crate::Agent::new`] and
/// [`crate::Summarizer::new`] take any of them.
///
/// Boxed rather than `async fn` in the trait, for the reason
/// [`crate::ToolFuture`] gives.
pub trait Model: Send + Sync {
    /// A name for this model in errors, such as the endpoint's configured
    /// name.
    fn name(&self) -> &str;

    /// Answers `request` in one response.
    fn generate<'a>(&'a self, request: &'a GenerateRequest) -> ModelFuture<'a, GenerateResponse>;

    /// Answers `request` as a stream of events.
    ///
    /// The default awaits [`Model::generate`] and replays the response with
    /// [`EventStream::from_response`], so a model that cannot stream still
    /// serves a streaming caller, all at once.
    fn stream<'a>(&'a self, request: &'a GenerateRequest) -> ModelFuture<'a, EventStream> {
        Box::pin(async move { Ok(EventStream::from_response(self.generate(request).await?)) })
    }
}

impl Model for Client {
    fn name(&self) -> &str {
        &self.config().name
    }

    fn generate<'a>(&'a self, request: &'a GenerateRequest) -> ModelFuture<'a, GenerateResponse> {
        Box::pin(Client::generate(self, request))
    }

    fn stream<'a>(&'a self, request: &'a GenerateRequest) -> ModelFuture<'a, EventStream> {
        Box::pin(Client::stream(self, request))
    }
}

impl<T: Model + ?Sized> Model for Arc<T> {
    fn name(&self) -> &str {
        (**self).name()
    }
    fn generate<'a>(&'a self, request: &'a GenerateRequest) -> ModelFuture<'a, GenerateResponse> {
        (**self).generate(request)
    }
    fn stream<'a>(&'a self, request: &'a GenerateRequest) -> ModelFuture<'a, EventStream> {
        (**self).stream(request)
    }
}

impl<T: Model + ?Sized> Model for Box<T> {
    fn name(&self) -> &str {
        (**self).name()
    }
    fn generate<'a>(&'a self, request: &'a GenerateRequest) -> ModelFuture<'a, GenerateResponse> {
        (**self).generate(request)
    }
    fn stream<'a>(&'a self, request: &'a GenerateRequest) -> ModelFuture<'a, EventStream> {
        (**self).stream(request)
    }
}
```
